## Four Beats

1. **Name the nest.** Give the SigmaNEST shop nest a short title before you place a part by eye.
2. **Pin the live parts.** Keep current shapes on the SigmaNEST nest layout and leave unused remnants aside.
3. **Read the path.** Open SigmaNEST cutting path before you move a part that already has a remnant.
4. **Check the remnant.** Read the SigmaNEST remnant sheet before you archive a nest.
5. **Close the loop.** Clear finished nests so the next SigmaNEST visit does not start with a search.
6. **Leave the table ready.** Keep the remnant aligned with the SigmaNEST shop nest on the desk.

## First Questions

**Does SigmaNEST replace every other program?**
No. SigmaNEST sits beside the table list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate SigmaNEST profile.

**Will SigmaNEST feel heavy on an older laptop?**
No. SigmaNEST is meant to stay readable during a normal nest session.

**What should a new user try first?**
One small SigmaNEST nest today, then the same remnant sheet tomorrow.

**Does the cutting path leave the remnant sheet?**
No. SigmaNEST cutting path stays with the SigmaNEST remnant sheet on the same shop nest.

**Is SigmaNEST only for a finished nest?**
No. SigmaNEST can hold a single remnant while the rest of the table stays off the board.

**Does the sheet need a second file for leftover stock?**
No. SigmaNEST keeps the nest and the remnant on this shop nest.

**Can a leftover sheet return to the next nest?**
Yes. A named SigmaNEST remnant sheet stays readable before the table starts.

## Field Note

SigmaNEST is easier to trust when the shop nest stays smaller than the folder it came from. A named sheet shows what is active, the part pins show what you will cut today, and the closing note tells the next person which remnant changed.

The same loop fits a single nest, a leftover sheet, or a table shared by two people. Open the last SigmaNEST shop nest, finish one cutting path, and leave fewer parts placed by eye than you found.

A review should not have to guess which remnant belongs to the open nest. Keep that pair together inside SigmaNEST.

## One Real Pass

Pick a sheet that already has a name. Open it in SigmaNEST, keep only those parts on the nest layout, and finish one cutting path you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different thickness and leave it out of this SigmaNEST shop nest.
